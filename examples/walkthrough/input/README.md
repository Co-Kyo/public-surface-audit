# shipAssets

一个 npm 包除了代码，往往还要带上模板、配置、示例这些文件。`shipAssets` 把它们收进一份名单，构建时按名单拷进输出目录，少一份就让构建失败。

```bash
npm install --save-dev @acme/asset-shipper
```

## 它做什么

- 从 `package.json` 的 `assets` 字段读名单，按「源文件 → 输出路径」逐条搬运。
- 构建后自动核对一遍：登记的文件在不在仓库里、派生路径落没落在输出目录之内、有没有两个登记项映射到同一个路径。
- 任一项对不上就以退出码 2 结束，日志里点名缺的那几个文件。

## 命令

| 命令 | 作用 |
|---|---|
| `shipAssets copy` | 按名单把文件写进输出目录 |
| `shipAssets check` | 只核对，不写盘；退出码 2 表示名单与产物不一致 |
| `shipAssets verify` | 构建后核对输出目录与名单是否一致 |

## 它不保证什么

- 登记文件的内容对不对、格式合不合规范，不在检查范围内。
- 输出目录里不在名单内的文件（比如 source map），不归它管。
