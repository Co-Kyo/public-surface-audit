# 步骤 01 · 装配取证包：让审计者拿到自足的输入

> 审计者的全部世界就是这一个包——包里没有的东西，对它等于不存在。

**输入**：轮次目录下的 `00-scope.md`。
**产物**：`.audit/rounds/{YYYY-MM-DD}-{slug}/01-package-B{n}.md`，每批一份。

## 做什么

每份取证包按顺序装五件，缺一件就重装：

1. **宪章全文**（`references/charter.md` 原文照贴，不要摘要——摘要即污染：你删掉的那一句，往往正是判据）。
2. **本批文件全文**。每个文件前写三行头：路径、它在哪条通道、谁读它。
3. **diff**（增量门模式）：这次改了什么，让审计者知道往哪盯；但简报里要写明**不许只盯 diff**，未改动段落同样逐句过判据。
4. **性质门提示一句**：工具承诺句／技能意图句／纯叙述（照抄 `00-scope.md` 的标注，不额外解释）。
5. **简报模板全文**（`references/brief-template.md`，逐字照贴，占位处填完）。

### 两件可以省的，与一件绝不能省的

宪章和模板实测共约 22KB，是每批的固定开销。省它有两种正当做法，都不算摘要：

- **共享附件**：同一轮里宪章／模板只放一份，各包用路径引用（`见本轮 00-charter.md`），审计者要读随时能读。判据完整可得，只是没有复制 N 份。
- **并批**：批次数 × 22KB 超过被审面总量时，回 `00-scope.md` 并批。十个薄批各贴一遍宪章，是拿固定开销淹没被审文字。

**绝不能省的是第 2 件的完整性**：本批的每个文件必须在包里，且原文逐字。审计者包里没有的东西，对它等于不存在。

### 注释体文件：装注释与字符串，不装代码骨架

CSS/SCSS/Less、纯配置文件里，面向读者的文字是**注释**，不是 `display:flex`。实测一个样式库：7 个 CSS 文件共 39,881 字节，其中注释 12,970 字节（32%）——68% 的包内容对审计者是零信息，而审计者要在 3,600 行样式里找 400 行文字。

这类文件按下面装：

- **注释全文**逐字照贴（含 `/* */`、`//`），保留原行号；
- **字符串字面量**（`content:`、模板文案）逐字照贴；
- **代码骨架**可省略，但要在包内标出省略范围（如 `L120–L340 为规则体，本批略，判据只在注释里`）。

这不违反"自足"：判据依赖的是文字，不是选择器。**保守起见也可以保留全文**，但要在包内标出"本批判断对象是第 N–M 行注释"，让审计者知道往哪看——不标而全文照贴，等于把找文字的成本转嫁给审计者。

## 禁止放进取证包的东西

- 写作过程记录、内部讨论、与本批无关的裁决行——**审计者必须像第一次见到这些文字一样读它**。"新上下文"的实质在此，不是"换个模型"。
- 主持者对某句的辩护（"这句是故意这么写的"）。辩护即预设立场。
- 其他批次的文件（会诱导跨批次合并判断）。

## 检查点

- 把取证包交给一个完全没参与过的读者，他能只凭这份包开始审吗？不能＝缺料，回补。
- 包里的文件是不是原文逐字，没有"顺手润色"？
- 性质门那一句，是不是和 `scope.md` 一字不差？
