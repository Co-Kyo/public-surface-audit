# 步骤 03 · 对抗复查与收口：一个陌生读者，然后给门凭据

> 你写的句子，你自己不知道它在陌生人眼里是什么意思。这一步骤只补这一件事，然后收口。

**输入**：`02-verdict.md`。
**产物**：`03-review.md`（复查记录）＋ `03-close.md`（收口记录，含**门凭据**一句话）。

## 一、对抗复查（只做一次，只问四个问题）

### 怎么派

开**一个**新上下文 agent（不是每批一个），输入只有两样：

1. 本批拟发布文件**全文**（不给 diff、不给旧版）；
2. `references/charter.md` 全文。

**不给**：裁决表、证据单、源码、图、写作过程、你自己的怀疑。给了它就替你的结论说话，这一步骤就白做了。

简报用 `references/review-brief.md`（逐字照贴，不临场改写）。

### 它做什么、不做什么

它**不**按宪章逐条判（那是重复劳动，机器和你在 01／02 已经做过）。它只描述**陌生读者的反应**：

1. 哪一句你读完不知道**谁在做**？
2. 哪一句像是**作者在跟自己说话**？
3. 哪一句你会**怀疑它做不到**？
4. 哪一句你**猜作者自己没意识到**它说了什么？

产出上限 10 条，每条只写 `文件:行` ＋ 一句反应。**不给红线号、不给改法**——它一判违规，就会开始迎合判据，而它唯一的资源是"我什么都不懂"。

### 拿到反应之后

| 反应 | 怎么处置 |
|---|---|
| 指向真实问题 | 进裁决表，本轮 FAIL，按步骤 02 的格式补推荐 |
| 是误读 | 记一行"复查者误读＋理由"——**误读本身是信息**：一个人误读，读者就可能误读，该改的是句子的清晰度，不是判据 |
| 越界判了违规并给了红线号 | 不采信判由，但**看它指的那句话**——它想说什么 |
| 一条没提 | 记"复查未提出，未提不等于没问题"（它只补盲区，不承诺覆盖率） |

**复查的产出不计入四值**，它是独立的第三层证据。裁决表里单列一节。

## 二、路由

1. **按类型路由**，一条发现只去一处，处置只有三种形态：**改／删／升级为待办**。

| 发现类型 | 去向 | 处置形态 |
|---|---|---|
| 文案本身要改（句子该改） | 呈报作者批 → 批了才改 → 改完复审受影响批次 | 改 |
| 属于"这条信息根本不该出门" | 删，不是改写——不做合规化处理 | 删 |
| 工具承诺句没有测试或构建期检查背书 | 缺口清单：补门 或 撤句，**二选一，不许挂着** | 改／升级为待办 |
| 实际行为与文档不符 | issue 清单：修实现，或修文档 | 升级为待办 |
| 判据本身有分歧（宪章没覆盖） | **停下问作者**——本程序无权自造规则 | 升级为待办（等人拍） |
| 词表召回误报，同类两轮以上 | 改 `scripts/redline-check.mjs` 规则，或记一条待办 | 升级为待办 |
| 只有实跑才暴露（读文本发现不了） | 标注出来，不在本程序处置 | 升级为待办 |

2. **收口**。作者批改写方案 → 改完 → 受影响批次复审 → 全部批次 PASS → 写 `03-close.md` 并记门凭据：
   "本轮（{YYYY-MM-DD}-{slug}）公开面审计：各通道各批 PASS，可发布。"

3. **门凭据只写在收口这一刻**，且必须能指到 `02-verdict.md` 的逐条证据——指不到就不算凭据。

4. **过程产物可删，记忆留下**：`.audit/rounds/{YYYY-MM-DD}-{slug}/` 跑完即可删——收口记录已归档，记录在就行。中断没跑完的，先更新 `STATE.md` 再走。`.audit/graphify-out/`、`claims.json`、`verdicts.json` 是跨轮记忆，留着；本轮若增删过源文件，用 `graph-audit reconcile` 把被驱逐的审计层补回图上（`update` 本身不会冲掉审计层，只有源文件消失才会）。

5. **涉及 push／tag／publish**：停在发布门前，本程序不执行发布。

## 什么时候本程序判为失败

- **已知违规没被逮住**（负向验证不过）→ 判据或取证有洞，回步骤 00 复盘，不许直接补审同一批。
- **没核对原文就出裁决** → 本轮作废重来。
- **`claims.json` 晚于任何核量记录**（先看了代码再抽声称）→ 本轮作废重来。
- **某条 FAIL 的去向列空着，或处置停在"二选一"没选** → 收口无效，门凭据不许写。
- **本轮没做对抗复查就写门凭据** → 收口无效。

## 检查点

- 复查 agent 是**一个**、且只拿到文本与宪章？（给了裁决表＝这步作废）
- 复查的每条反应都有处置（进裁决／记误读／记未提）？
- 每条"驳倒"都有去向，且只有一个？
- 承诺句缺口是真选了"补门"或"撤句"，不是挂着？
- 门凭据这句话能不能逐条指回裁决表？
- 复审只覆盖了受影响批次，没顺手放行未复审的批？
